# Random Password Generator — Python

## About the Project
This project is a **Random Password Generator** developed using Python as part of my Oasis Infobyte Python Programming Internship (Task 3). It generates strong, randomized passwords based on user-defined length and character complexity criteria.

## Features
- **Custom Length Control:** Enforces a secure minimum length of 8 characters.
- **Character Diversity:** Supports uppercase letters, lowercase letters, numbers, and symbols.
- **Robust Validation:** Rejects invalid lengths and requires valid numerical inputs.
- **Interactive Loop:** Provides an option to generate another password instantly without restarting the program.

## Technologies Used
- Python 3
- Built-in modules: `random`, `string`

## How to Run
1. Ensure Python 3 is installed on your system.
2. Open the `Python-Task3-PasswordGenerator` folder in your terminal.
3. Run the script using the command:
   ```bash
   python password_generator.py
