# Weather App - Python

## About the Project
This project is a command-line Weather Application developed in Python as part of the Oasis Infobyte Python Programming Internship. It retrieves and displays real-time weather information for any requested city using the OpenWeatherMap API.

## Features
- Real-time weather data retrieval (Temperature, Feels Like, Humidity, Pressure, Weather Condition).
- Temperature converted and displayed in Celsius (`units=metric`).
- Robust input handling and error checking for invalid city names, missing API keys, or connection failures.
- Built strictly using Python standard libraries (`urllib` and `json`), requiring no third-party package installations.

## Technologies Used
- Python 3
- OpenWeatherMap API
- Modules: `urllib.request`, `urllib.parse`, `json`
