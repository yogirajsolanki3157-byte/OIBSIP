BMI Calculator — Python

About the Project

This project is a Body Mass Index (BMI) Calculator developed using Python as part of my Oasis Infobyte Python Programming Internship.

Features

- Accepts weight in kilograms.
- Accepts height in meters.
- Calculates BMI using the formula: BMI = Weight / (Height × Height).
- Classifies BMI as Underweight, Normal Weight, Overweight, or Obese.
- Displays the BMI result to two decimal places.
- Handles invalid numerical input.

Technologies Used

- Python 3

How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Run "bmi-calculator.py".
4. Enter your weight in kilograms and height in meters.
